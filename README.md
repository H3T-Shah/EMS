# EMPLOYEE MANGEMENT SYSTEM

**Problem Statement** - Maintain employee ID, name, department and salary details; search, update and display records.

### General Requirements
- Functions, structures and file handling are compulsory and must be used meaningfully in the implementation.
- Arrays and pointers are expected to be used wherever appropriate to the selected problem.
- Of course, other basic structures (branching, looping, etc) will be inevitably be useful in your implementation.
- The program should be suitably divided into user-defined functions rather than being written entirely in main().
- Files should be used for persistent storage of relevant records/data.
- The project should preferably provide a simple menu-driven interface suitable for the selected problem.
- The group must prepare the algorithm and/or flowchart before writing the C program.
- The source program should be properly organized and should contain meaningful comments.
- Every member of the group is expected to understand the complete project and should be able to explain the program during evaluation.

### Evaluation Scheme
| Criterion                                  | Marks |           Indicative Aspects            |
|--------------------------------------------|-------|-----------------------------------------|
| Understanding                              | 5     | Understanding of the problem, data representation and program logic; ability of individual members to explain the implementation.Important Note: This 'understanding' component is essential for these projects. Students who show ‘no understanding’ of the implementation or logic may receive a score of zero out of 15.    |
| Implementation and Working                 | 5     | Correct implementation and working; appropriate use of functions, structures and file handling; correctness for suitable test cases.     |
| Algorithm / Flowchart and Program Quality  | 5     | Algorithm and/or flowchart (3); program organization, readability and meaningful comments (2).     |

**Note**: The Understanding component may be assessed individually during demonstration/viva, even though the project is carried out as a group.
